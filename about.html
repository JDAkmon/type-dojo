typedojo

A better instinct for every battle.

Type Dojo helps teens and adults learn Pokémon's game-based type advantages, resistances, and immunities through practice, stories, and familiar Pokémon.

From zero to type hero

Start with the Fire, Water, and Grass triangle in Ground Zero. Build up to immunities, unfamiliar types, and dual-type multiplication. Memory hooks turn abstract numbers into pictures, such as water putting out fire.

Your study plan revisits specific mistakes, with spaced reviews and later recall. Move-choice battles use moves checked against the exact species and a named game. A Type Hero challenge celebrates your progress.

Rules that match the games

Choose Generation I, Generations II–V, or Generation VI onward to practice the standard type chart for that era. Move examples name their source game because learnsets vary even within one chart era.

Exercises isolate type effectiveness. Power, STAB, stats, abilities, weather, and special battle transformations can change actual damage. This tool does not use Pokémon GO or trading-card rules.
