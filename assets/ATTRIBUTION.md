# Pokémon sprite attribution

Pokémon sprite images are provided by [the PokéAPI sprite repository](https://github.com/PokeAPI/sprites). Animated sprites use the Generation V Black/White style; still sprites come from the default Pokémon collection. The same art style is used across game-rule eras, while species availability and typings follow the selected chart era.

The source repository identifies image contents as copyright The Pokémon Company and distributes its repository under CC0 1.0 Universal. The original source notice is preserved in `pokemon/SOURCE-LICENSE.txt`. Pokémon characters, names, and trademarks remain the property of their respective owners. This is an unofficial fan learning project.

Each downloaded file's original URL is listed in `pokemon/sources.json`. All images are served locally; using the app does not call PokéAPI or another external service.

The pixel-art landscape and interface decorations are original vector artwork created for Type Dojo.
