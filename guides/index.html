Learn Pokémon type matchups

A reading path from your first type advantage to immunities, dual types, and historical game rules.

Start with attack direction, then learn the zeroes, combine two defending types, and check the rules of your game. Each guide includes worked examples and a question you can answer before opening the explanation. All guides can be read without an account or JavaScript.

  • Type effectiveness: read the attack, then the defender

    Learn the direction of the type chart, the four basic multipliers, and how to remember your first matchups.

  • Type immunities: learn the zeroes without guessing

    Understand the standard type immunities, their direction, and the generation changes that affect them.

  • Dual-type damage: multiply both matchups

    Calculate 4× weaknesses, ¼× resistances, neutral combinations, and immunities with worked examples.

  • Generation differences: which type chart should you learn?

    Compare Generation I, Generations II–V, and Generation VI onward, with the matchups that changed.

Read, recall, then practice

After reading one guide, close its examples and explain a matchup in your own words. Check the answer, practice a few mixed questions, and return later. Use the app’s progress notebook to find the pairs you keep confusing. Understanding one mistake is more useful than rushing through a whole chart.
